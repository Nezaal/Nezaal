## `~/projects` 🚀

### 🤖 SkillBridge AI &nbsp;·&nbsp; `Oct 2024` &nbsp;·&nbsp; Full-Stack GenAI Job Preparation Platform

> *AI-native career intelligence — resume analysis, structured interview reports & personalised roadmaps powered by Google Gemini.*

```
TECH  →  React 19 · Node.js · Express · MongoDB · Google Gemini API · JWT · pdf-parse · Vite · Sass
```

| What was built | Detail |
|:---|:---|
| 🧠 **AI Interview Engine** | Architected Gemini (`gemini-2.5-flash`) backend with enforced JSON schemas to auto-generate structured reports — technical assessments, behavioural analysis & skill-gap identification |
| 🔐 **JWT Auth System** | Secure token issuance, protected route middleware & session-aware report access for user-scoped career roadmaps |
| 📄 **PDF Resume Pipeline** | `pdf-parse` ingestion for unstructured resume extraction — enabling context-aware LLM analysis against job descriptions |
| ⚙️ **Controller-Service Architecture** | Decoupled design orchestrating multipart form-data, async LLM calls & MongoDB sync for real-time report generation |
